# CSM-2026-2027-Batch-B-20-NLP-Based-American-Sign-Language-Translation


American Sign Language (ASL) is an important means of communication for the Deaf and hard-of-hearing community, but communication barriers arise when non-sign-language users cannot understand ASL.

This project proposes an NLP-Based American Sign Language Translation System that converts information from multiple input modalities into meaningful ASL representations.
